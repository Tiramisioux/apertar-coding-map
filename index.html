The same calls the WebUI makes. Values are strings, because Core's parser is flat.

curl -s -m 5 http://apertar.local:8000/api/state | grep -o '"iso":[0-9]*'

This one changes the camera:

curl -s -m 5 -X POST http://apertar.local:8000/api/command -d '{"cmd":"set_iso","value":"800"}'

Rebuild after a change: UI cmake --build ~/ApertarUI/build, Core cmake --build ~/ApertarCore-build -j2, then restart that service.
